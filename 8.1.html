Modul 08

/ Firebase Authentication

Autentikasi Pengguna & Keamanan Hak Akses

Memahami sistem login/register pengguna berbasis Email & Password menggunakan Firebase Authentication, serta membatasi hak akses kontrol dan dashboard IoT.

1

Konsep Dasar Firebase Authentication

Firebase Authentication menyediakan layanan backend siap pakai untuk mengautentikasi pengguna pada aplikasi web dan IoT. Dengan autentikasi, kita dapat mengamankan Realtime Database sehingga hanya pengguna terverifikasi yang berhak membaca atau mengontrol perangkat fisik.

Registrasi (Sign Up)

Mendaftarkan akun baru menggunakan email dan kata sandi via createUserWithEmailAndPassword().

Login (Sign In)

Verifikasi identitas pengguna via signInWithEmailAndPassword() untuk memperoleh token otorisasi.

State Observer

Memantau status sesi login secara realtime via onAuthStateChanged() untuk proteksi halaman web.

3. Implementasi Kode Program (`auth.js`)

index.html (Firebase Auth Module)
// 1. Import Modul Authentication 
import { initializeApp } from "https://www.gstatic.com/firebasejs/10.8.0/firebase-app.js";
import { 
  getAuth, 
  signInWithEmailAndPassword, 
  createUserWithEmailAndPassword,
  signOut,
  onAuthStateChanged 
} from "https://www.gstatic.com/firebasejs/10.8.0/firebase-auth.js";

// Konfigurasi Proyek Firebase Anda
const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "latihaniot.firebaseapp.com",
  projectId: "latihaniot"
};

const app = initializeApp(firebaseConfig);
const auth = getAuth(app);
// 2. Fungsi Login dan Register 
// Fungsi Login
async function loginUser(email, password) {
  try {
    const userCredential = await signInWithEmailAndPassword(auth, email, password);
    console.log("Login Berhasil:", userCredential.user.email);
  } catch (error) {
    alert("Gagal Login: " + error.message);
  }
}

// Memantau Status Sesi Pengguna
onAuthStateChanged(auth, (user) => {
  if (user) {
    // Pengguna terautentikasi -> Tampilkan Dashboard
    document.getElementById("protectedPanel").classList.remove("hidden");
  } else {
    // Pengguna belum login -> Sembunyikan Dashboard
    document.getElementById("protectedPanel").classList.add("hidden");
  }
});
Aturan Keamanan Realtime Database Terautentikasi (Security Rules)

Setelah mengaktifkan Firebase Auth, ubah aturan Realtime Database Anda agar hanya pengguna yang berhasil login (auth != null) yang dapat membaca dan menulis data sensor.

// Rules dengan Pembatasan Autentikasi Pengguna:
{
  "rules": {
    ".read": "auth != null",
    ".write": "auth != null"
  }
}
