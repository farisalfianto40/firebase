Modul 02 • CSS

2.1 CSS Dasar (Selector, Color, Font, & Box Model)

Penerapan seleksi elemen, pewarnaan indikator sensor, tipografi, serta konsep tata letak Box Model untuk antarmuka dashboard IoT.

01

CSS Selector (Tag, Class, & ID) untuk Elemen Dashboard

Selector digunakan untuk memilih elemen HTML pada dashboard web IoT yang ingin diberi gaya visual (seperti panel status ESP32 atau kartu sensor).

selector.html 
<h1 id="judul-dashboard">
  Dashboard IoT SMTI
</h1>

<div class="sensor-card">
  <p>Suhu Ruangan: 28.5 °C</p>
</div>
style.css 
#judul-dashboard {
  color: #0284c7;
  text-transform: uppercase;
}

.sensor-card {
  background-color: #f1f5f9;
  padding: 12px;
}
http://localhost:5500/selector.html

Dashboard IoT SMTI

Suhu Ruangan: 28.5 °C

Jenis-Jenis Selector Utama pada Dashboard IoT

  • Tag Selector: Menargetkan elemen HTML berdasarkan nama tag-nya (contoh: h1, p).
  • Class Selector: Menargetkan elemen kartu sensor menggunakan simbol titik (.sensor-card).
  • ID Selector: Menargetkan judul utama dashboard secara unik menggunakan simbol pagar (#judul-dashboard).
02

Pewarnaan & Tipografi Indikator Sensor (Color & Font)

Pengaturan warna teks status, latar belakang kartu metrik, jenis huruf monospace untuk data angka, serta ketebalan font.

font.html 
<div class="nilai-suhu">
  28.5 °C (Optimal)
</div>
style.css 
.nilai-suhu {
  color: #059669;
  background-color: #ecfdf5;
  font-family: 'JetBrains Mono', monospace;
  font-size: 16px;
  font-weight: 700;
}
http://localhost:5500/font.html
28.5 °C (Optimal)

Penjelasan Properti Color & Tipografi Data IoT

  • color & background-color: Menentukan warna indikator status sensor (misal hijau untuk kondisi normal/optimal).
  • font-family (Monospace): Sangat direkomendasikan untuk angka telemetri sensor agar posisi digit angka tetap lurus dan mudah dibaca secara real-time.
  • font-size & font-weight: Menentukan ukuran serta ketebalan angka pengukuran sensor.
03

CSS Box Model (Margin, Padding, Border) pada Widget Dashboard

Konsep tata letak kotak yang mengatur jarak antar komponen widget pengukuran sensor ESP32 di halaman web.

box-model.html 
<div class="widget-sensor">
  Text
</div>
style.css 
.widget-sensor {
  padding: 16px;
  border: 2px solid #0284c7;
  margin: 12px;
  box-sizing: border-box;
}
http://localhost:5500/box-model.html
MARGIN (12px)
BORDER (2px)
PADDING (16px)
Text

Komponen Utama Box Model pada Layout Dashboard

  • Content: Area utama tempat nilai sensor atau teks status berada.
  • Padding: Jarak dalam antara angka sensor dengan bingkai widget.
  • Border: Garis tepi pembatas kartu widget monitoring.
  • Margin: Jarak luar yang memisahkan widget satu dengan widget sensor lainnya.
04

Studi Kasus: Kartu Widget Monitoring Sensor ESP32

Penggabungan seluruh materi CSS untuk membangun komponen kartu monitoring suhu ruangan berbasis ESP32 dan sensor DHT11.

card_sensor.html 
<div class="sensor-widget">
  <h3 class="card-title">Suhu Ruangan</h3>
  <div id="nilai-sensor">28.5 °C</div>
  <p class="status-teks">
    Status: Terhubung ke Firebase
  </p>
</div>
style.css 
.sensor-widget {
  width: 240px;
  padding: 20px;
  border: 1px solid #cbd5e1;
  border-radius: 12px;
  background: #ffffff;
}

.card-title {
  font-size: 14px;
  color: #64748b;
  margin-bottom: 8px;
}

#nilai-sensor {
  font-size: 28px;
  font-weight: 800;
  color: #059669;
  margin-bottom: 8px;
}

.status-teks {
  font-size: 11px;
  color: #0284c7;
}
http://localhost:5500/card_sensor.html

Suhu Ruangan

28.5 °C

Status: Terhubung ke Firebase

Ringkasan Integrasi CSS untuk Dashboard IoT

  • Ukuran Widget: Properti width: 240px dan padding: 20px menjaga tata letak kartu metrik sensor tetap rapi.
  • Skala Angka Sensor: Ukuran font besar (28px) dengan ketebalan tinggi memudahkan pemantauan telemetri secara visual.
