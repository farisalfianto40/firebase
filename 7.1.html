01

Render Baris Tabel (<td>) dengan JavaScript

Pada HTML biasa, tag <tbody> dibiarkan kosong. JavaScript akan membaca Array of Objects (simulasi database) lalu membuatkan elemen <tr> dan <td> secara dinamis.

latihan_tabel.html 
<table border="1">
  <thead>
    <tr>
      <th>No</th>
      <th>Waktu</th>
      <th>Suhu (°C)</th>
      <th>Kelembapan (%)</th>
    </tr>
  </thead>
  <!-- Target penampung baris data -->
  <tbody id="dataTabel"></tbody>
</table>

<script>
  // 1. Simulasi Database Array
  const dbSensor = [
    { waktu: "08:00", suhu: 27.5, kelembapan: 65 },
    { waktu: "08:05", suhu: 29.1, kelembapan: 62 },
    { waktu: "08:10", suhu: 32.8, kelembapan: 58 },
    { waktu: "08:15", suhu: 30.2, kelembapan: 60 },
    { waktu: "08:20", suhu: 28.4, kelembapan: 63 }
  ];

  // 2. Ambil elemen tbody
  const tbody = document.getElementById("dataTabel");

  // 3. Perulangan untuk membuat tag <td>
  dbSensor.forEach((item, index) => {
    tbody.innerHTML += `
      <tr>
        <td>${index + 1}</td>
        <td>${item.waktu}</td>
        <td>${item.suhu} °C</td>
        <td>${item.kelembapan} %</td>
      </tr>
    `;
  });
</script>

02

Membuat Grafik dengan Elemen <canvas> & Chart.js

Chart.js membutuhkan tag HTML <canvas> sebagai wadah gambar grafik. Library Chart.js dimuat menggunakan CDN pada bagian header HTML.

latihan_chart.html 
<!-- 1. Include Library Chart.js di head/body -->
<script src="https://cdn.jsdelivr.net/npm/chart.js"></script>

<!-- 2. Tag HTML Canvas tempat grafik digambar -->
<div>
  <canvas id="grafikSuhu"></canvas>
</div>

<script>
  // 1. Database Simulasi Array
  const dbSensor = [
    { waktu: "08:00", suhu: 27.5, kelembapan: 65 },
    { waktu: "08:05", suhu: 29.1, kelembapan: 62 },
    { waktu: "08:10", suhu: 32.8, kelembapan: 58 },
    { waktu: "08:15", suhu: 30.2, kelembapan: 60 },
    { waktu: "08:20", suhu: 28.4, kelembapan: 63 }
  ];

  // 2. Ekstrak data dari Array DB Simulasi
  const labelJam = dbSensor.map(row => row.waktu);
  const nilaiSuhu = dbSensor.map(row => row.suhu);

  // 3. Hubungkan dengan Canvas ID
  const ctx = document.getElementById('grafikSuhu');
  
  new Chart(ctx, {
    type: 'line',
    data: {
      labels: labelJam,
      datasets: [{
        label: 'Suhu Telemetri',
        data: nilaiSuhu,
        borderColor: '#0284c7'
      }]
    }
  });
</script>
