Modul 01 • HTML

1.1 Tag Dasar, Semantik & Tabel

Fondasi penyusunan halaman web interaktif serta pengelolaan data sensor berbasis tabel untuk sistem pemantauan IoT.

02

Heading (<h1> - <h6>)

Heading digunakan untuk mendefinisikan judul panel, status ruangan, atau sub-menu pada dashboard web monitoring IoT.

heading.html 
<!DOCTYPE html>
<html lang="id">
<head>
    <title>Dashboard IoT SMTI</title>
</head>
<body>
    <h1>Monitoring Suhu Ruang</h1>
    <h2>Sensor ESP32 & DHT11</h2>
</body>
</html>
http://localhost:5500/heading.html

Monitoring Suhu Ruang

Sensor ESP32 & DHT11

03

Paragraph (<p>)

Digunakan untuk menuliskan deskripsi status sistem, keterangan waktu pembaruan data terakhir, atau instruksi penggunaan alat.

paragraf.html 
<p>Status Koneksi: Terhubung ke Firebase Realtime Database.</p>
<p>Data diperbarui secara otomatis setiap 2 detik.</p>
http://localhost:5500/paragraf.html

Status Koneksi: Terhubung ke Firebase Realtime Database.

Data diperbarui secara otomatis setiap 2 detik.

04

Membuat Tabel Data Sensor IoT (<table>, <tr>, <th>, <td>)

Dalam proyek IoT, tabel sangat penting untuk menampilkan riwayat pengukuran sensor (datalogger), status pin aktuator, atau konfigurasi perangkat. Berikut adalah penjelasan elemen dasar pembuatan tabel:

<table>

Wadah utama pembungkus seluruh elemen tabel.

<tr>

Table Row (baris horizontal pada tabel).

<th>

Table Header (sel judul kolom, teks tebal otomatis).

<td>

Table Data (sel isi data atau nilai sensor).

tabel_sensor.html 
<table border="1">
  <tr>
    <th>Waktu</th>
    <th>Suhu (°C)</th>
    <th>Kelembapan (%)</th>
  </tr>
  <tr>
    <td>10:00:15</td>
    <td>28.5</td>
    <td>65</td>
  </tr>
</table>
http://localhost:5500/tabel_sensor.html
Waktu Suhu (°C) Kelembapan (%)
10:00:15 28.5 65
05

Hyperlink (<a>) & List (<ul>, <ol>)

Digunakan untuk membuat menu navigasi utama aplikasi web IoT (menghubungkan halaman Monitoring, Control, dan Database).

navigasi.html 
<ul>
    <li><a href="monitoring.html">Monitoring</a></li>
    <li><a href="control.html">Control</a></li>
    <li><a href="database.html">Database</a></li>
</ul>
http://localhost:5500/navigasi.html
  • Monitoring
  • Control
  • Database
06

Image (<img>)

Digunakan untuk menampilkan skema rangkaian elektronika atau diagram skematik ESP32 pada halaman web materi.

skema.html 
<img 
    src="img/dht11.png" 
    alt="Skematik ESP32 DHT11" 
    width="350" 
/>
http://localhost:5500/skema.html
