Pengantar IoT & Firebase Realtime DB

Memahami konsep dasar Internet of Things (IoT), arsitektur komunikasi sensor-ke-cloud, dan cara kerja Firebase Realtime Database.

1

Apa itu Internet of Things (IoT)?

Internet of Things (IoT) adalah jaringan perangkat fisik ("things") yang tertanam dengan sensor, perangkat lunak, dan teknologi lain dengan tujuan menghubungkan dan mempertukarkan data dengan perangkat dan sistem lain melalui internet.

Perangkat/Hardware

Mikrokontroler seperti ESP32 yang membaca data fisik via sensor (suhu dan kelembapan).

Cloud / Database

Layanan backend seperti Firebase Realtime DB untuk menyimpan dan mendistribusikan data secara instant.

Web Dashboard

Antarmuka pengguna (UI) berbasis HTML/JS untuk monitoring angka dan grafik telemetri real-time.
