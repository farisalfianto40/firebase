/ Persiapan Firebase

Langkah Kerja Membuat Database di Firebase

Panduan komprehensif penyiapan proyek, Realtime Database, aturan keamanan, serta pengambilan kredensial untuk Web & ESP32. Klik pada gambar untuk memperbesar.

A

Tahap 1: Membuka & Membuat Proyek Firebase

01 - 02

Buka browser dan masuk ke situs resmi Firebase: https://firebase.google.com/, kemudian klik tombol Get started di halaman utama.

03 - 04

Klik Create a project, beri nama proyek contoh: latihaniot, lalu centang persetujuan dan klik Continue.

05 - 06

Pada konfirmasi AI Assistant dan opsi Google Analytics, klik tombol Continue.

07 - 08

Pilih Default Account for Firebase pada konfigurasi Analytics, klik Create project, lalu klik Continue setelah proyek siap.

B

Tahap 2: Menyiapkan Realtime Database & Struktur Data

09 - 10

Buka menu side-bar Build → pilih Realtime Database, lalu klik tombol Create Database.

11 - 12

Pilih opsi lokasi database default, lalu pilih mode keamanan Start in locked mode dan klik Enable.

13 - 15

Tambahkan Key utama (Parent Node) dht11 dengan mengklik tombol +, lalu tambahkan Child Key suhu dengan Value 27.20.

16 - 17

Klik ikon + pada node dht11 untuk menambahkan Key kedua yaitu kelembapan dengan Value 75.50, lalu klik Add.

C

Tahap 3: Mengonfigurasi Aturan Keamanan (Database Rules)

18 - 19

Pilih tab Rules, ubah pengaturan ".read" dan ".write" menjadi true, lalu klik tombol Publish.

// Rules untuk Mode Pembelajaran/Praktikum:
{
  "rules": {
    ".read": true,
    ".write": true
  }
}
D

Tahap 4: Registrasi Web App & Menyimpan Kredensial

20 - 21

Masuk ke menu Project Settings (ikon roda gigi) → tab General, lalu klik ikon Web (</>) untuk menambah aplikasi web baru.

22 - 23

Isikan nama aplikasi contoh: web-iot, klik Register app, lalu salin konfigurasinya (firebaseConfig) sebelum menekan Continue to console.

24 - 26

Pilih tab Service accounts → Database secrets, lalu salin kunci Database Secret untuk dihubungkan dengan ESP32 di Arduino IDE.

27 - 28

Kembali ke laman Realtime Database, simpan URL Database (berakhiran .firebaseio.com). Seluruh proses konfigurasi Firebase telah selesai!

Ringkasan Parameter Penting yang Harus Dicatat:

1. Untuk Program Web (index.html)

• apiKey: "AIzaSy..."

• databaseURL: "https://...firebaseio.com"

• projectId: "latihaniot-..."

2. Untuk Hardware ESP32 (.ino)

• DATABASE_URL: "https://...firebaseio.com"

• DATABASE_SECRET: "xYz123..."
